# Lettering preview fonts

Freely licensed look-alikes used by the Try Your Lettering section of
`pcm-design-catalog.html` to preview PCM's lettering styles. PCM's own fonts are
commercial and are not in this repository. Each file here is one static face,
subset to Latin by `scripts/prep_pcm_lettering.py`; the license travels in the
font's own name table.
