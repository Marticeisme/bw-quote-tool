## How

PDFs are generated by `node scripts/build_guide_pdfs.mjs` (Playwright print of each
page's own print stylesheet, then Ghostscript downsampling). So the lever is each guide's
`@media print` CSS (plus print-only/screen-only classes where needed):

- Tighten type, margins, and vertical rhythm for print; multi-column where it reads well.
- Cut for print what a leave-behind doesn't need: oversized hero art, decorative spacers,
  long duplicated preambles. Prefer `display:none` in print CSS over touching markup;
  small print-only summaries are allowed where a long section must compress.
- **Never lose substance: every PRICE, every table row of prices, and every hard rule
  (eligibility, deadlines, legal citations like RCW references) present in today's PDF
  must be present in the condensed PDF.** Prose may compress; data may not.
- Keep the existing brand: navy/orange, fleur logo, page numbers — consistent with
  GPL-April-2026 branding already used across the guides.
- Screen rendering must not change: screen CSS untouched (print-only rules added), and
  verify with the existing verifiers.
- Rebuild all target PDFs with `node scripts/build_guide_pdfs.mjs` (same filenames — the
  guides.html download links must keep working with zero edits to guides.html).
